# Buddyfit Growth Audit

**Live → https://eddieatadapty.github.io/buddyfit-flow-rebuild/**

Five ideas to turn more Buddyfit users into subscribers, each built into a clickable version of Buddyfit's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask their goal before the paywall, then name it there | +15–20% CR to purchase |
| 02 | Let them press play before they pay | +5–15% CR to purchase |
| 03 | Make the 14 free days predictable | +5–10% CR to purchase |
| 04 | Make the yearly price add up | +5–15% ARPU |
| 05 | Offer 6 months to people who close the paywall | +5–10% CR from paywall closers |

Every price, rating and feature comes from Buddyfit's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Buddyfit. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
